## 这轮新增的两个入口

- 新建会话时向已连接主机读取 `agentPresets/list`。主机实际返回并可用的 `tw-standard`、`tw-research`、`tw-teach`、`tw-study` 才会出现在选择器，随后通过主机会话 API 应用并核对。普通主机可继续采用桌面默认预设。
- 已连接的主机页面增设「学校额度」。它用现有主机会话读取 `dsh-ustc-quota` 1.1.20 的版本 1 快照，显示额度余额、上限、重置和过期状态。需由一台受信任且已认证的兼容 HTTPS 主机提供该路由。桌面插件的本机内部端口应保留在本机，移动端访问通过有认证的入口。 [额度插件及版本协议](https://www.npmjs.com/package/dsh-ustc-quota/v/1.1.20)

## 2026-11-19 dsh-Go 移动端功能

- 多主机：统一保存 HTTPS、SSH 和 Remote 主机，支持切换、改名、删除、自动连接上次主机和旧单主机凭据迁移。
- SSH：密码/私钥认证、SHA-256 指纹 TOFU、托管启动和只连接隧道。`dartssh2` 4.1.0 只协商 `none` 压缩；托管实例复用采用本项目保存的端口和令牌，不声称复刻上游托管状态文件。
- DSH Remote：账号登录、主机目录、指纹信任和 Noise 加密会话。首版只走 Relay，直连和扫码配对未接入。
- 自动化任务：主机目录、筛选/搜索、详情、历史、编辑、立即运行和删除。新建按官方路径交给对话模型，不新增私有 RPC。
- 插件：已安装开关与卸载撤销，真实 format-1 市场索引、安装检查、风险确认和构建脚本批准。完整设置表单仍待迁移。
- 语音通话：系统识别、分句朗读、插话、静音、免提/听筒、后台挂断和手动审批。

上述完成度指代码与可控测试，不等于真机或真实主机验收。

验证目标是用 Android 连接已登录学校账号的授权 TokenWorks 测试主机，核对四种模式和额度数值，再确认 Office/PDF、文献与知识工作室各自的桌面契约。构建和验证命令见[质量门禁](quality.md)。
